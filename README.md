# KBHB Radio Website

A production website built for **KBHB Radio**, developed with **Next.js** to modernize the station's web presence while providing listeners with quick access to local news, weather, sports, programming, and community information.

> **Note:** This repository represents an archived implementation. The live website has since been redesigned and replaced, but this project demonstrates the architecture and implementation of the original Next.js application.

---

## Overview

This project was designed as a fast, responsive, content-driven news and radio website with a focus on performance, usability, and maintainability.

The application combines traditional news publishing with dynamic content such as weather, sports, events, and syndicated programming while providing an optimized experience across desktop and mobile devices.

## Features

* Responsive Next.js application

* Weather integration
* News and article management
* Sports coverage

## Architecture

The application is organized around reusable UI components and feature-specific modules, separating presentation, page composition, utilities, and data access.

High-level responsibilities include:

* Page layouts
* Content rendering
* Shared UI components
* Weather integration
* Navigation
* Media assets
* Utility helpers
* API communication

This approach allowed features to be developed independently while maintaining a consistent user experience throughout the site.
